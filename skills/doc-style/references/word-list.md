# Reference: Word list

Paraphrased from the Google developer documentation style guide word list (https://developers.google.com/style/word-list), snapshot 2026-10-09, CC BY 4.0. Look up a term here before you use it. Follow the source link for terms that are not in this table.

| Term | Use | Note |
| --- | --- | --- |
| & | and | OK in UI labels, tight table headings, diagrams, and code. |
| abort | avoid; use stop, exit, cancel, or end | OK as the name of the Linux signal. |
| above | earlier, preceding (document); later (versions) | Do not use it for a place in the UI. |
| access (verb) | see, edit, find, use, view | Use a plainer verb when you can. |
| admin | administrator | Keep "admin" when a UI label uses it. |
| aka | also known as, or parentheses | — |
| allowlist (verb) | rewrite the sentence | The noun "allowlist" is OK. |
| allows you to | lets you | — |
| and so on, and so forth | avoid; use "such as" or "including" | — |
| and/or | "a or b, or both" | OK only where space is tight, such as a table. |
| anti-pattern | a more specific term | Do not use it alone as a heading. |
| API | API | Means a web or language API, not one method or class. |
| API key | API key | Not "developer key" or "dev key". |
| app, application | app | "Application" is OK for complex enterprise software. |
| as (meaning because) | because | "As" can also refer to time. |
| as of this writing | avoid; delete it | The present tense already says this. |
| authenticate, authorize | users are authenticated; requests are authorized | Write "authenticate against". |
| authN, authZ | authentication, authorization | — |
| autoupdate | automatically update | — |
| back-end, back end | backend | — |
| bar, baz, foo | a meaningful placeholder name | — |
| below | later, following (document); earlier (versions) | Do not use it for a place in the UI. |
| between, among | between for distinct items; among for a group | — |
| big endian, Big-endian | big-endian | Lowercase, with a hyphen. Same for little-endian. |
| blacklist | denylist, blocklist, excludelist | For verbs, say the action, such as "deny requests". |
| boolean | code font for a keyword; lowercase for the type | Capital B for Boolean logic or math. |
| button | button | A link is not a button. |
| careful, carefully | avoid; give the exact step | It can sound condescending. |
| cell phone, cellphone | mobile phone, phone | "Mobile device" if tablets are included. |
| check (a checkbox) | select | — |
| check box | checkbox | — |
| choose | select (UI elements) | "Choose" is OK in general text. |
| CLI | the name of the specific CLI | Do not use "CLI" in a general sense. |
| click | click | Not "click on". Use "tap" on touch devices. |
| click here | descriptive link text | — |
| click through, clickthrough | click through (verb), clickthrough (noun) | — |
| client | client (the app that the developer writes) | Do not use it for "client library"; use "library". |
| comprise | consist of, contain, include | — |
| config | configuration | Keep "config" only for literal code names. |
| console | the full console name, with "the" | Not "console" alone. |
| Control+S | Control+S (Command+S on macOS) | Not "Ctl-S" or "Cmd-S". |
| copy and paste | enter | Say what to enter, not how. |
| could | can | — |
| Create a new | Create a | Keep "new" only to tell two new items apart. |
| currently | avoid; delete it | — |
| dash (meaning -) | hyphen | A dash (—) and a hyphen (-) are different. |
| data | singular mass noun | "The data is", "less data". |
| data store | datastore | — |
| deprecated | deprecated (not recommended) | Do not use it to mean removed or shut down. |
| deselect (a checkbox) | clear | — |
| desire, desired | want, need | — |
| directory, folder | directory (command line), folder (GUI) | Match the tool. If not sure, use directory. |
| disable, disabled | turn off, deactivate, unavailable | Do not use it to mean broken. |
| display (no object) | appears, is displayed | "Displays" needs an object. |
| doc, article, topic | this document | Spell out "documentation". |
| does not yet | avoid; state the current fact | — |
| drag and drop, click and drag | drag | "Drag-and-drop" is OK as an adjective. |
| drop-down | list, menu | Keep it only as a modifier to prevent confusion. |
| dummy (placeholder) | placeholder | In statistics: indicator variable. |
| e-mail, E-mail | email | Not a verb; write "send email". |
| e.g. | for example, such as | — |
| each (meaning all) | all | "Each" means items one at a time. |
| easy, easily | avoid; delete it | Easy for you can be hard for others. |
| enables you to | lets you | Use "enable" for turning on a feature. |
| etc. | avoid; use "such as" or "including" | If you must use it, keep the period. |
| eventually | avoid | It goes out of date. |
| execute | run | Keep "execute" only if "run" is not exact. |
| fail over, failover | fail over (verb), failover (noun) | — |
| file name | filename | — |
| filepath, pathname | path | — |
| fill in, fill out | fill in a field; fill out a form | — |
| for instance | for example, such as | "Instance" has a technical meaning. |
| front-end, front end | frontend | — |
| functionality | capabilities, features | Often overused. |
| future, in the future | avoid | It goes out of date. |
| GB/s, Gb/s | GBps (bytes), Gbps (bits) | Same pattern for KBps, Kbps, MBps, Mbps. |
| grayed-out | unavailable | — |
| hang, hung | stop responding, not responding | — |
| hard-code | hardcode | No hyphen. |
| he, she, he/she, (s)he | they, their | Use a gendered pronoun only for a known person. |
| health check, healthy | responsive, or the UI term | Use "health check" only if the UI does. |
| high availability | high availability (noun), high-availability (adjective) | HA after first use. Same for load balancing. |
| higher (versions) | later | Android docs use "higher". |
| hit | click, press, type | — |
| host name | hostname | — |
| hover | hold the pointer over | Use "point to" if no wait is needed. |
| i.e. | that is | — |
| Id, id | ID | Lowercase only in string literals or enums. |
| if | if ... then | Keep "then" in conditions. |
| image | disk image, container image | "Image" alone is vague for translators. |
| impact (verb) | affect | The noun "impact" is OK. |
| in order to | to | Keep it only when it adds clarity. |
| in-line, in line | inline | — |
| index | plural: indexes | "Indices" only in math or finance. |
| ingest | import, load, copy | Use "ingest" only with significant processing. |
| interface (verb) | interact, communicate | — |
| Internet | internet | Lowercase. |
| just | avoid; delete it | If the meaning needs it, use a more exact word: only, instead, or previously. |
| k8s | Kubernetes | — |
| key (adjective) | important, crucial | For the noun, name the type of key. |
| key/value pair | key-value pair | — |
| kill | stop, exit, cancel, end | OK in literal command syntax. |
| later | "2.2 or later" | Not "2.2 or higher" or "2.2+". |
| latest | avoid; give a version or date | — |
| let's | avoid | — |
| leverage | use, build on | — |
| life cycle | lifecycle | — |
| like | like | OK for examples and comparisons. |
| limit | usage limit, service limit | Say which type of limit. |
| log in, login | sign in (verb), sign-in (noun) | Use "log in" if the tool says so. |
| log out | sign out (verb), sign-out (noun) | — |
| lower (versions) | earlier | Android docs use "lower". |
| master | primary, main, controller, leader | Never pair it with "slave". |
| may | can (permission), might (possibility) | Keep "may" for policy or legal text. |
| method (meaning approach) | approach, way | In code docs, "method" is a class member. |
| MIME type | media type | — |
| mobile (noun) | mobile phone, mobile device | — |
| native | built-in | "Cloud-native" is vague; say what you mean. |
| new, newer | avoid; give a version or date | "Newer version" becomes "later version". |
| now | avoid; delete it | OK to compare past and present. |
| old, older | earlier | Give a version number. |
| on (a topic) | about | "For more information about X". |
| on-prem, on-premise | on-premises | Always with a hyphen. |
| once (meaning after) | after | — |
| per (outside rates) | for each, according to | Not "per the guide" or "as per". |
| performant | fast, accurate, or a more exact word | — |
| persist (transitive) | make persistent | Not "the token is persisted". |
| please | avoid in instructions | Never "please note". |
| plugin | plugin (noun), plug in (verb) | — |
| pop-up, popup | dialog, menu | — |
| populate (by a person) | fill in | A process can populate a table. |
| possible, impossible | you can, you can't | — |
| presently, at present | avoid | — |
| press | press (keys, hardware buttons) | Tap on-screen buttons. |
| proper, properly | avoid; state the exact condition | — |
| pros, cons | advantages, disadvantages | — |
| quick, quickly | avoid | — |
| quota | usage limit | Google Cloud docs use "quota". |
| read only | read-only | — |
| regex | regular expression | — |
| repo | repository | — |
| review (meaning read) | read | "Review" is for critical reading, such as code review. |
| roll out | gradual, in stages | Define it. It does not mean an instant launch. |
| runtime, run time | runtime (environment), run time (when) | — |
| sane | valid, sensible | — |
| sanity check | quick check, confidence check | — |
| scale (alone) | at a larger scale; scale up, down, out, in | Show size or direction. |
| screen shot, screenshot (verb) | screenshot (noun); take a screenshot | — |
| scroll | go to | Not "scroll up" or "scroll down". |
| select | select | For options, text, and checkboxes. |
| set up, setup | set up (verb), setup (noun) | — |
| shall | avoid | Use it only with legal advice. |
| should | avoid | It is unclear. Say if the step is required or optional. |
| sign into | sign in to | — |
| signin, signout | sign in, sign out (verbs); sign-in, sign-out (nouns) | — |
| simple, simply | avoid; delete it | — |
| since (meaning because) | because | — |
| single pane of glass | single interface, unified interface | — |
| slave | replica, worker, secondary | Pairs: primary/replica, leader/follower. |
| smartphone | mobile phone, phone | — |
| soon | avoid | — |
| spin up | create, start | OK for hard disks. |
| ssh, SSH (verb) | connect by using SSH | Not "ssh into" or "ssh'ing". |
| start up, startup | start up (verb), startup (noun) | — |
| surface (verb) | make available, expose | — |
| tap | tap (touch screens) | Not "touch". Use "click" with a mouse. |
| target (verb) | intended for, focus on | Avoid it for people. |
| terminate | stop, exit, cancel, end | OK where it is a technical term. |
| text box, textbox | box; field in Google Cloud docs | — |
| they | they (singular) | Always with a plural verb. |
| third party | third party (noun), third-party (adjective) | Not "3rd party". |
| this, that | add a noun after it | — |
| time out, timeout | time out (verb), timeout (noun) | — |
| time zone | time zone (noun), time-zone (adjective) | — |
| tl;dr | "To summarize" | — |
| turn on, enable | turn on or enable | Pick one and use it throughout. |
| type | enter | Text can also be pasted or spoken. |
| typically | typically | Do not start a sentence with it. |
| UI | page, console, web interface | Do not use "UI" for a page. |
| unarchive, uncompress, untar, unzip | extract | — |
| uncheck | clear | — |
| under | "in the X field"; earlier (versions) | Do not use it for a place in the UI. |
| unselect | clear (checkbox), deselect (other elements) | — |
| user | you (for the reader) | "User" means the user of the reader's software. |
| using | by using, that use | Use these when "using" is ambiguous. |
| utilize | use | OK for amounts of a resource, such as CPU. |
| via | avoid; use "through", "by using", or "with" | — |
| vice versa | state both directions, or "conversely" | — |
| vs. | versus | — |
| we | you (for the reader) | "We" is OK for the author company. |
| web server, webserver | web server | — |
| while (contrast) | although | OK for time. |
| white space | whitespace | — |
| whitelist | allowlist, safelist, trustlist | For verbs, say the action, such as "allow". |
| will, would | present tense; can | — |
| wish | want, need | — |
| with (ownership) | that has | "A server that has 4 CPUs", not "a server with 4 CPUs". |
| workload | define it | It has many meanings. |
| World Wide Web, Web | web | — |
